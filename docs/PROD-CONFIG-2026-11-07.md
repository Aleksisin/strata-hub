## 4. Серверная командная строка (снята с живого процесса 07.11)

```
llama-server.exe
  -m  <MODEL>                 # см. §2
  --mmproj <MMPROJ>           # vision-проектор
  --host 127.0.0.1 --port 8107
  -ngl 99                     # все тензоры на GPU
  -c 131072                   # контекст 128K (у модели нативно 262K, но
                              #   256K на q4_0 KV не влезает в 16 GiB)
  -np 1                       # один слот (одна 16ГБ карта = один движок)
  -fa on                      # flash attention
  -ctk q4_0 -ctv q4_0         # KV-кэш квантован в q4_0: 18 KB/токен
                              #   (против 36 KB у q8_0) — это то, что
                              #   позволяет 128K вообще влезть
  --reasoning-budget 16384    # кап думы на запрос (см. §6)
  --jinja --chat-template-kwargs "{\"reasoning_effort\":\"low\"}"
  --temp 0.6 --top-p 0.95 --top-k 20 --min-p 0.05   # рецепт APEX
  --threads 8
```

VRAM-бюджет: веса 11.2 GB + KV q4_0 ~2.25 GiB @131K + буферы ≈
**15.5–15.8 GiB из 16.0** (замер после тяжёлой серии: 15 772 MiB из 16 303).
Hermes-совместимость: n_ctx ≥ 64 000 выполняется с двойным запасом.

Загрузчик: задача планировщика `StrataHub\NP3-START` →
`launch\START-NANOPLUS-V3.bat` (guard свободной VRAM ≥ 12 000 MiB,
проверка занятых портов 8090/8099/8102/8106/8110, ожидание /health,
лог `launch\nanoplus-v3-server.log`).

## 5. Сэмплинг: сервер vs раннер

Два уровня; на агентных задачах **payload раннера перекрывает серверные
дефолты** per-request:

| параметр | сервер (дефолт) | AgentBench-раннер (payload) |
|---|---|---|
| temperature | 0.6 | **0.2** |
| seed | — | **42** (детерминизм траекторий) |
| max_tokens | — | **16384/запрос** |
| top-p / top-k / min-p | 0.95 / 20 / 0.05 | не перекрываются |

Серверный рецепт 0.6/0.95/20/0.05 — вендорский APEX-реципиент с карточки
модели (для прямых чатов/Hermes). Для строгого кода карточка допускает
temp 0.2–0.3 — что раннер и использует.

## 8. Контур AgentBench (кто и как ходит на 8107)

```
schtasks StrataHub\SUPERVISOR  (пид-сторож, очередь queue/pending)
   └─ agentbench_runner.py  (sha256 c385ee1d — патч auto_red_count +
        строгий fvp; капы из freeze-abx5b, §9)
        └─ http://127.0.0.1:8109/v1/chat/completions  (AgentGW)
             ├─ схема: 10 bench-инструментов + pyapi + localdocs MCP
             └─ http://127.0.0.1:8107  (этот сервер; NP 1, слот один)
localdocs: 127.0.0.1:6280 (библиотеки, read-only)
турнирный контур (dsh/pi): прямое 8107, БЕЗ agentgw, изолированный worktree
```

Контурная дисциплина: 16 ГБ карта = один движок; панель 8090, Cyber-Tiel
8099/8102, FlashNext-Coder 8106, DeepSeek 8110 с продом не совмещаются.
