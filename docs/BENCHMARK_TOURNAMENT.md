## 3. Методология прогона на тестируемой модели

1. Панель с тестируемой моделью running (одна, соло); другие движки погашены.
2. Сэмплер метрик запущен на порт модели.
3. Диспетчер (pi-operator) получает карточку kanban с заданием
   (шаблон: `Strata-Hub\reports\NANOBENCH_CARD_TEMPLATE.md`).
4. Тестируемая модель исполняет задачи; Identity
   `--model <модель> --harness "pi-1.4.0 via hermes" --quant <квант> --source user_reported`.
5. Результат фиксируется; сэмплер остановлен; строки добавляются в раздел 2
   этой таблицы; sync.sh.
