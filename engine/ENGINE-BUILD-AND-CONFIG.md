движка = смена выходной дистрибуции модели → полная перевалидация по
методологии, поэтому обновления запрещены вне воронки E1.

показать build 11985 / commit 6f4cc4d72.

## 2. Полная командная строка прода

```
llama-server.exe
  -m  <MODEL.gguf>            # Qwen3.8-27B-EfficientThink-VAL-APEX-I-NanoPlus-V3
  --mmproj <MMPROJ.gguf>      # vision-проектор Q4_K_M (498 MiB)
  --host 127.0.0.1 --port 8107
  -ngl 99                     # все тензоры на GPU
  -c 131072                   # контекст 128K (нативно у модели 262K, но
                              #   256K на q4_0 KV не влезает в 16 GiB)
  -np 1                       # один слот — одна 16ГБ карта = один движок
  -fa on                      # flash attention
  -ctk q4_0 -ctv q4_0         # KV-кэш q4_0: 18 KB/токен (против 36 у q8_0) —
                              #   именно это позволяет 128K влезть в 16 GiB
  --reasoning-budget 16384    # кап думы на запрос (см. §4)
  --jinja --chat-template-kwargs "{\"reasoning_effort\":\"low\"}"
  --temp 0.6 --top-p 0.95 --top-k 20 --min-p 0.05   # APEX-рецепт модели
  --threads 8
  --metrics                   # Prometheus-эндпоинт (наблюдаемость)
```

VRAM-бюджет: веса 11.2 GB + KV q4_0 ~2.25 GiB @131K + буферы ≈
**15.5–15.8 GiB из 16.0**. Запускать вместе с другими движками на той же
карте нельзя.

## 4. Механизм `--reasoning-budget`

Файл `common/reasoning-budget.cpp` в llama.cpp: сэмплер со состояниями
IDLE → COUNTING → FORCING → DONE. Пока бюджет не исчерпан, `apply()` —
passthrough. При исчерпании бюджета сэмплер **принудительно завершает
последовательность конца-думания** и генерация продолжается без
reasoning — запрос НЕ аброртится, ответ и tool_calls доходят до клиента.
Это отличается от `max_tokens`-бёрна (тот даёт `finish=length` без
контента). На задачах-марафонах (монологи вместо действий) кап
переключает модель на действия; на здоровых задачах (пик думы 7.2K)
кап 8192–16384 не срабатывает вовсе.

Сравнение на 5 задачах (07.11): кап 8192 — 4/4 решаемых зелёные, bf2
1307с против 2580с; полная 10-задачная серия — отдельный эксперимент.
